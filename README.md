# HeroBuilder Tracker

The issue tracker for [Hero Builder](https://herobuilder.io), a build planner for Hero Siege.

There is no source code here. This repository exists to take bug reports, wrong numbers and
feature requests. Pull requests will be closed unchanged.

## Send your build link. It is the whole report.

Open the build on herobuilder.io, press **Copy link** in the top bar, and paste the result into
the issue.

That URL carries the entire build: class, gear, runes, sockets, charms, skill ranks, incarnation
and ether nodes. Anyone who opens it sees exactly the screen you were looking at. A report with a
link is reproducible in one click. A report without one has to be rebuilt by hand from a
description, and most never are.

If the bug is that the site will not load or the link will not restore, paste the link anyway.
A link that fails to open is the evidence.

## What belongs here

**A bug.** The site crashes, renders blank, a control does nothing, a shared link does not come
back the way it went in.

**A wrong number.** The planner says one thing and the game says another. Use the "Wrong number"
form and attach a screenshot of the in-game tooltip. The game client is the authority. A tooltip
settles the disagreement in seconds.

**A feature request.** What you want and what you are trying to do with it.

## What does not belong here

**Hero Siege itself.** Game bugs, balance, drops, accounts, purchases and refunds are Panic Art
Studios' business, not ours. We cannot act on them.

**Build advice.** "What should I put in this slot" is not a bug. Ask in whichever Hero
Siege community you use.

**Security problems.** Read [SECURITY.md](SECURITY.md) first. Do not open a public issue for one.

## Two things to include every time

Search the open issues before you file. Duplicates are closed and the trail gets split across
both.

Copy the build id from the site footer. It reads `build` followed by a short id. It tells us which
version of the site you were on, which is often the difference between a live bug and one already
fixed.
